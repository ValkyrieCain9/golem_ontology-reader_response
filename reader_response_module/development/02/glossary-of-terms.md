# Iteration 2 - Glossary of Terms

| Term | Definition |
| ---- | ---------- |
| `Digital Object` | An object with at least one bitstring as a component part and a layered strucutre of immaterial and material bearers, with at least one material bearers of some kind in order for the object to be used, stored, or communicated. |
| `Bitstring` | A type of syntactic object made from a binary numbering system, structured according to specific file formats so as to be machine readable. |
| `Syntactic Expression` | An immaterial object made up of a set of symbols arranged into well-formed expressions |
| `Bearer of non-material object` | Non-material objects can be bourne, inscribed or contained within another object, which becomes the bearer of that non-material object. Bearers can be either material or immaterial objects. |
| `Program File` | An encoded sequence of logical experessions used to carry out specific types of computation |
| `Data File` | Encoded data which includes, documents, datasets, images, videos, audio recordings |
| `Translation Actions` | A set of practices which move a bitstring entity from one layer of a bearer to another |
| `Social Position` | The properties which define an object's expected fuctions, rights and responsibilities attributed to that object. This also defines what sort of translation actions can be peformed on the digtial object. |
