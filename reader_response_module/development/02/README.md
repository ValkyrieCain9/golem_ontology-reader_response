# Iteration 2 - Motivating Scenario

## Name
Digital Objects

## Description
As comments, and the posts they respond to, are created, shared and stored within the digital space, they need to be understood as digital objects. Faulkner and Runde (2019) provide a set of definitions to describe the nature of the digtial object, taking into account both its material and immaterial aspects. A digital object is described as a bitstring, a type of immaterial syntatic experession, which is bourne by some sort of material or immaterial bearer. Bitstrings are subdivided into program files (software and computing) and data files (data and documents). 

A digital object can be formed from a layering of several different bearers, but at least the bottom most layer must be a material carrier in order for the digtial object to be used, stored or communicated. Translation actions describe the set of practices which the respresenation of a digtial object from one structural layer to another. 

The properties of a particular digital object are set by what Faulkner and Runde describe as an object's social position. The social position is what describes an object's expected fuctions, rights and responsibilities attributed to that object. This also defines what sort of translation actions can be peformed on the digtial object.

*Faulkner, P., & Runde, J. (2019). Theorizing the Digital Object. MIS Quarterly, 43(4), 1279–1302.*

## Example 1
A user creates a response which is bourne onto the immaterial bearer of a natural language text expression. This text expression is then bourne by a data file in HTML. This HTML bearer is then borne by the software which requests retrieves and displays the HTML and all of these bearers and objects are bourne by the material bearer of the user's device.

## Example 2
The social position of the website AO3 is described by its function as a "a noncommercial and nonprofit central hosting place for fanworks using open-source archiving software". From this a set of translation actions can be described - reading, posting (adding stories to the website in the form of bitstring content), commenting (adding responses to the stories on the website in the form of bitstring content) archiving (adding stories to library and lists). The latter three actions can only be performed by a user with an account on the website, while the first action (reading) can be performed without an account but with limited capabilities.
