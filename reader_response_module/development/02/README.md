# Iteration 2 - Motivating Scenario

## Name
Digital Objects

## Description
As comments, and the posts they respond to are created, shared and stored within the digital space, they need to be understood as digital objects. Faulkner and Runde (2019) provide a set of definitions to describe the nature of the digtial object, taking into account both its material and immaterial aspects. A digital object is described as a bitstring, a type of immaterial syntatic experession, which is bourne by some sort of bearer. Bitstrings aresubdivided into program files (software and computing) and data files (data and documents). Bearers of immaterial objects can themselves be material or immaterial and a digital object can be formed from a layering of several different bearers, but at least the bottom most layer must be a material carrier in order for the digtial object to be used, stored or communicated. 

With this set of defintions, digital objects can be described in the context of their immaterial aspects or material aspects or both, with the idea of bearers allowing for the digital objects to be described with varying degrees of complexity. Therefore when looking at the creative content bourne onto these digtial obejcts, the dependance on a material bearer is implied even if it is not explicitly stated.

*Faulkner, P., & Runde, J. (2019). Theorizing the Digital Object. MIS Quarterly, 43(4), 1279–1302.*

## Example 1
A user creates a response which is bourne onto the immaterial bearer of a natural language text expression. This text expression is then bourne by a data file in HTML. This HTML bearer is then borne by the software which requests retrieves and displays the HTML and all of these bearers and objects are bourne by the material bearer of the user's device.
