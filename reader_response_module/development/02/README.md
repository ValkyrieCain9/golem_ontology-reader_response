## Name
Digital Objects, Websites and Webpages

## Description
As comments, and the posts they respond to, are created, shared and stored within the digital space, they need to be understood as digital objects. Faulkner and Runde (2019) provide a set of definitions to describe the nature of the digital object, taking into account both its material and immaterial aspects. A digital object is described as a bitstring, a type of immaterial syntactic expression, which is borne by some sort of material or immaterial bearer. Bitstrings are subdivided into program files (software and computing) and data files (data and documents). 

A digital object can be formed from a layering of several different bearers, but at least the bottom most layer must be a material carrier in order for the digital object to be used, stored or communicated. Translation actions are the set of practices which describe the representation of a digital object from one structural layer to another. 

The properties of a particular digital object are set by what Faulkner and Runde describe as an object's social position. The social position is what describes an object's expected functions, rights and responsibilities attributed to that object. This also defines what sort of translation actions can be performed on the digital object.

From this description, the nature of digital objects on the internet can be better understood. The interne itself can be thought of as a complex digital object made from the interaction between different layers of material objects (servers) and immaterial objects (networking protocol and software). With this the internet provides the structure for the identification, interaction and exchange of different digital recourses in any format. 

The most common of these resources is the webpage which, in its most basic form, is a digital object made from a HTML data file and supplementary program files which provide its functioning. Often times webpages are made up mainly of text (in markup language and natural language) but they cab also act as bearers of other digital object types like images, videos and audio, encoded in their respective formats.

A website is a collection of webpages, all linked to a single domain name, which is synonymous with the name of the website. A website and its webpages are identified and located, by the URL (Uniform Resource Locator), a string organised in a hierarchical structure, starting from the website domain and stepping down to the nested webpages and resources found on the webpages. 

*Faulkner, P., & Runde, J. (2019). Theorizing the Digital Object. MIS Quarterly, 43(4), 1279–1302.*

## Example 1
A website’s social position is what determines the structure, formatting and functions of its webpages as well as influencing the type of digital objects which can be found on them. 

**YouTube** – social website for sharing videos – videos, audio, text </br>
**AO3** – community-run website for sharing fanfiction – text </br>
**Reddit** – website for forum communities of any kind – video, images, text </br>
**GitHub** – website for cloud storage of software – csv files, Json files, html files, python scripts etc. </br>

## Example 3

On social websites, like Reddit, AO3 and YouTube, which grow from community engagement, there are two main action users, those interacting with the digital structure of a website, can perform to contribute to the website. Firstly, they can create a post. Posting often results in the creation of a new webpage containing textual content, or digital objects shared by the user. 

Comparatively, the action of commenting does not create a further subdivision of webpages but instead it adds content, textual or otherwise to an existing post webpage. Many websites structure their post webpages to include a section under the main post where one can see the comments attached to it.
